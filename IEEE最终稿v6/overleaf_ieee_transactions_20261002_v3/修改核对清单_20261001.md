# 导师意见核对

中文题目：已知总时长与同段信息共享下的分段运行时间估计。

| 要求 | 本次落实 |
|---|---|
| 学术语言与具体表达 | 依据scientific-writing规范重写中英文摘要、引言、方法、实验解释和结论；删除改稿过程及抽象的贡献口号。 |
| 引言无子标题 | 两种语言的引言均为连续段落，不使用subsection。 |
| 段落衔接 | 按运营需求、时间定义、分配歧义、已有方法、设计动机和实证发现展开。 |
| 动机例子 | 三个连续区间、十分钟总量、中段三分钟，比较(2,3,5)与(5,3,2)。明确是解释性算例。 |
| 贡献回应例子 | 同段共享利用其他行程信息，行程修正调整本次分配，总时长决定输出尺度；明确结构设计与准确率是不同命题。 |
| 问题和方法的区别 | 已知有序有向站间区间、有限单区间标签、共享条件基础估计和相对幅度受限的行程内修正。 |
| 与已有工作对照 | 阅读原论文，区分交通流似然分解、共享链路概率推断、GPS局部辅助预测、聚合监督与预测协调。来源和方法位置见文献报告。 |
| 内部状态用语 | 正文改用训练、验证、评估与重复初始化；不逐项罗列随机数编号、封存状态或改稿轮次。真正影响解释的评价条件集中说明。 |
| 最优值与实验图 | 可比表格按完整精度确定最优值并加粗；方法对比图和消融图均为单栏宽度的3行×2列分面，Python绘图程序、逐次CSV/JSON、彩色与灰度图同包提供。柱内不加纹理，消融图高度由5.65英寸压至4.65英寸，并保留从零起的纵轴。 |
| 补充实验 | 此前新增5%预算18次神经训练、6次简单基线计算和9次修正参数化训练；本轮新增36次三布局消融/参数化训练，均保存预测、配置、检查点、验证历史与哈希审计。 |
| IEEE结构 | 官方未改动IEEEtran，五节：Introduction、Related Work、Methodology、Experiments、Conclusion；数据和指标放实验，无Discussion占位。 |
| 框架图 | 按要求保留空白图位，提供与实现一致的中英文提示词，不擅自插入生成图片。 |
